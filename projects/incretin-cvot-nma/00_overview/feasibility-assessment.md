## Novel Contribution

Existing NMAs are limited:
1. Most restrict to T2DM populations — **we include non-diabetic ASCVD** (SELECT, SURMOUNT-MMO)
2. None include all of: SOUL (2025) + SURPASS-CVOT (2025) + SELECT (2023) simultaneously
3. Tirzepatide (dual GLP-1/GIP agonist) is a new drug class not in older NMAs
4. Bayesian approach with SUCRA ranking for clinical decision-making

## Decision Rationale

**GO** — This is an ideal NMA candidate:
- Star-shaped network with placebo as common comparator
- 10+ large RCTs with consistent endpoint reporting
- High clinical relevance (incretin therapies are first-line for CV risk reduction)
- Clear novelty: first NMA spanning all incretin classes including non-diabetic populations

**Anticipated challenges**:
- Population heterogeneity: some trials T2DM-only, others include/focus on non-diabetic obesity (SELECT, SURMOUNT-MMO) — address via subgroup/sensitivity analysis
- SURMOUNT-MMO may not have full results by April 2026 — include if available, sensitivity analysis without it
- Some trials have multiple semaglutide doses — treat as separate nodes or pool per protocol

**Mitigation strategies**:
- Pre-specified subgroup: T2DM vs non-T2DM populations
- Sensitivity analysis excluding non-T2DM trials
- Network meta-regression for % T2DM as effect modifier
- Separate nodes for different doses where clinically distinct (e.g., semaglutide 1mg vs 2.4mg)
